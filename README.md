## C. কোথায় কী কোড আছে

তিনটা মূল ফাইলের কাজ আলাদা — এটা বুঝলে বাকি সব সহজ হয়ে যাবে:

| ফাইল | এটা কী করে | সহজ উদাহরণ |
|---|---|---|
| **index.html** | ওয়েবসাইটের **কাঠামো** — কোন টেক্সট, কোন বাটন, কোন সেকশন কোথায় থাকবে | মানুষের শরীরের কঙ্কাল |
| **style.css** | ওয়েবসাইটের **ডিজাইন** — রং, ফন্ট, স্পেসিং, সাইজ | চামড়া ও জামাকাপড় |
| **script.js** | ওয়েবসাইটের **আচরণ** — মেনু খোলা/বন্ধ, ফর্ম সাবমিট, স্ক্রল এফেক্ট | শরীরের নড়াচড়া |

আপনি তিনটা ফাইলই সম্পূর্ণ, কাজ-করা অবস্থায় পাচ্ছেন — নতুন করে কিছু লিখতে হবে না, শুধু প্রয়োজনমতো এডিট করবেন। নিচের সেকশনগুলোতে ঠিক কোথায় কী বদলাবেন তা বিস্তারিত দেখানো আছে।

### ✏️ কী এডিট করবেন, কী রাখবেন

- ✅ **এডিট করুন:** লেখা/টেক্সট, লিংক (`href`), ছবির ফাইলের নাম, `style.css`-এর `:root` অংশের রং/ফন্ট ভ্যারিয়েবল।
- ⚠️ **সাধারণত না বদলানোই ভালো** (যদি না জানেন এটা কী করে): HTML-এর `class="..."` নামগুলো, `id="..."` গুলো, আর script.js-এর কোড লজিক — এগুলো ডিজাইন আর ফাংশনালিটি একসাথে ধরে রাখে। এগুলো বদলে ফেললে ওয়েবসাইট ভেঙে যেতে পারে।

## D. কীভাবে ওয়েবসাইট রান করবেন

দুইটা পদ্ধতি আছে:

### পদ্ধতি ১: সরাসরি ব্রাউজারে খোলা (সবচেয়ে সহজ)
1. আপনার **portfolio** ফোল্ডার খুলুন।
2. **index.html** ফাইলে ডাবল-ক্লিক করুন।
3. এটা আপনার ডিফল্ট ব্রাউজারে খুলে যাবে — ব্যস, ওয়েবসাইট রেডি!

### পদ্ধতি ২: VS Code Live Server (এডিট করার সময় ভালো)
1. VS Code-এ বাম পাশে **Extensions** আইকনে ক্লিক করুন (চারটা স্কয়ার আইকন)।
2. সার্চ বক্সে লিখুন **Live Server** (Ritwick Dey-এর তৈরি) → **Install** চাপুন।
3. index.html ফাইলের উপর **right-click** করুন → **Open with Live Server** সিলেক্ট করুন।
4. ব্রাউজার নিজে থেকেই খুলে যাবে (সাধারণত `http://127.0.0.1:5500` ঠিকানায়)।
5. এখন থেকে কোড বদলে **Save (Ctrl+S)** করলেই ব্রাউজার নিজে থেকে refresh হয়ে যাবে!

**কোনটা ব্যবহার করবেন?** একদম নতুন হলে পদ্ধতি ১ দিয়ে শুরু করুন। বারবার এডিট করতে হলে, আর প্রতিবার refresh করতে বিরক্ত লাগলে, পদ্ধতি ২ (Live Server) ব্যবহার করুন।

## H. কীভাবে CV যোগ করবেন

1. আপনার CV/Resume **PDF** আকারে সেভ করুন (Word বা Google Docs থেকে "Export as PDF" / "Download as PDF")।
2. ফাইলের নাম বদলে রাখুন ঠিক **cv.pdf**।
3. এটা **assets** ফোল্ডারে রাখুন।
4. ব্যস — Hero সেকশনের **Download CV** বাটন এখন থেকে আপনার আসল CV ডাউনলোড করাবে।

index.html-এ বাটনটা এভাবে লেখা আছে:
```html
<a href="assets/cv.pdf" class="btn btn--outline" download>Download CV</a>
```
`download` শব্দটার মানে হলো — ক্লিক করলে ব্রাউজার ফাইলটা নতুন ট্যাবে না খুলে সরাসরি ডাউনলোড করবে। চাইলে `download="আপনার-নাম-CV.pdf"` লিখে ডাউনলোড হওয়া ফাইলের নামও কাস্টমাইজ করতে পারেন।

## I. রং পরিবর্তন

সব রং **style.css** ফাইলের একদম শুরুতে, `:root` এর ভেতরে একসাথে রাখা আছে:

```css
:root {
  --color-bg: #F8FAFC;             /* পেজের ব্যাকগ্রাউন্ড */
  --color-text: #0F172A;           /* মূল লেখার রং */
  --color-text-secondary: #475569; /* হালকা/সেকেন্ডারি লেখার রং */
  --color-accent: #0F766E;         /* মূল থিম কালার — বাটন, লিংক, হাইলাইট */
  --color-accent-hover: #115E59;   /* হোভার করলে একটু গাঢ় রং */
  --color-card: #FFFFFF;           /* কার্ড/বক্সের ব্যাকগ্রাউন্ড */
  --color-border: #E2E8F0;         /* বর্ডার/লাইনের রং */
}
```

**উদাহরণ: সবুজ থেকে নীল করতে চাইলে**, শুধু accent দুটো বদলান:
```css
--color-accent: #2563EB;
--color-accent-hover: #1D4ED8;
```
Save করে Refresh করলেই পুরো ওয়েবসাইটের বাটন, লিংক, চিপ, হাইলাইট — সব জায়গায় নতুন রং দেখা যাবে, কারণ পুরো ফাইলজুড়ে সবাই এই একই ভ্যারিয়েবল ব্যবহার করছে।


**২) style.css-এর `:root` এ:**
```css
--font-family: 'Manrope', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
```

**ফন্ট বদলাতে চাইলে:**
1. [fonts.google.com](https://fonts.google.com)-এ গিয়ে পছন্দের ফন্ট বাছাই করুন (যেমন Poppins)।
2. ওখান থেকে `<link>` কোডটা কপি করে index.html-এর উপরের লিংকটার জায়গায় বসান।
3. style.css-এ `--font-family`-এর ভেতরে `'Manrope'`-এর জায়গায় `'Poppins'` লিখুন।

## K. প্রজেক্ট পরিবর্তন

index.html-এর Projects সেকশনে প্রতিটা প্রজেক্ট একটা `<article class="project-card">` ব্লকের ভেতরে থাকে। এর ভেতরে যা যা আছে:

|---|---|
| ছবি | `src="assets/project-1.jpg"` |
| টাইটেল | `<h3>Modern Landing Page</h3>` |

| Live Demo বাটন | দ্বিতীয় `<a>` ট্যাগ (`btn--primary`) |

এই একই স্ট্রাকচার তিনটা প্রজেক্টের জন্যই আছে (Modern Landing Page, Task Manager, Personal Dashboard)। যেটা বদলাতে চান, সেই টেক্সট বা লিংক খুঁজে নতুন করে লিখুন।

## L. নতুন প্রজেক্ট যোগ করা

1. index.html-এ যেকোনো একটা প্রজেক্ট কার্ড বেছে নিন — `<article class="project-card reveal">` থেকে শুরু করে তার মিলে যাওয়া `</article>` পর্যন্ত পুরো অংশটা **সিলেক্ট করে কপি করুন**।
2. শেষ প্রজেক্ট কার্ডের `</article>`-এর ঠিক পরে **পেস্ট করুন** (তখনও `<div class="projects__grid">`-এর ভেতরেই থাকতে হবে)।
3. নতুন কপি করা অংশে ছবি, টাইটেল, বর্ণনা, ট্যাগ আর লিংকগুলো বদলে দিন।
4. `assets` ফোল্ডারে একটা নতুন ছবি যোগ করুন (যেমন `project-4.jpg`), অথবা ছবি ছাড়াই রেখে দিন — placeholder দেখাবে।

**লেআউট নিয়ে চিন্তা করার দরকার নেই** — CSS grid নিজে থেকেই নতুন কার্ডের জন্য জায়গা বানিয়ে নেবে আর রেসপন্সিভও থাকবে। কোনো CSS বদলাতে হবে না।

## M. নেভবার পরিবর্তন

মেনুর লিংকগুলো index.html-এর নেভবার অংশে `<ul class="navbar__links">`-এর ভেতরে আছে:
```html
<ul class="navbar__links">
  <li><a href="#home" class="nav-link">Home</a></li>
  <li><a href="#about" class="nav-link">About</a></li>
  ...
</ul>
```
- **নাম বদলাতে:** `<a>` ট্যাগের ভেতরের লেখাটা বদলে দিন।
- **নতুন আইটেম যোগ করতে:** একটা `<li>...</li>` কপি করে নতুন একটা পেস্ট করুন, তারপর তার `href="#..."` অংশটা কোনো সেকশনের `id`-এর সাথে মিলিয়ে দিন।

**উদাহরণ:** নতুন সেকশন `<section id="blog">` থাকলে, মেনু আইটেম হবে:
```html
<li><a href="#blog" class="nav-link">Blog</a></li>
```
`href="#blog"` আর `id="blog"` — দুইটার বানান ঠিক এক হতে হবে, তাহলেই ক্লিক করলে ঐ সেকশনে স্ক্রল হয়ে যাবে।

## R. ওয়েবসাইট ডিপ্লয় (পাবলিশ) করা

### পদ্ধতি ১: Netlify Drop (সবচেয়ে সহজ, রিকমেন্ডেড)

1. ব্রাউজারে যান **[app.netlify.com/drop](https://app.netlify.com/drop)**।
2. আপনার কম্পিউটারের ফাইল এক্সপ্লোরার থেকে পুরো **portfolio** ফোল্ডারটা ঐ পেজের নির্দিষ্ট বক্সে **drag করে ছেড়ে দিন (drop)**।
3. সাথে সাথেই একটা লাইভ লিংক পাবেন (যেমন `random-name-123.netlify.app`) — সাইন-আপ ছাড়াই!
4. এই লিংকটা স্থায়ীভাবে রাখতে চাইলে ফ্রি অ্যাকাউন্ট বানিয়ে সাইটটা **claim** করে নিন — নাহলে এটা অস্থায়ী থাকবে।
5. অ্যাকাউন্ট বানানোর পর চাইলে Site settings থেকে সাইটের নাম বদলে নিজের পছন্দমতো করতে পারবেন (যেমন `yourname.netlify.app`)।

### পদ্ধতি ২: GitHub Pages (বিকল্প)

1. একটা ফ্রি GitHub অ্যাকাউন্ট বানান, তারপর একটা নতুন **repository** বানান (যেমন নাম দিন `portfolio`, Public রাখুন)।
2. রিপোজিটরির ভেতরে **Add file → Upload files** বাটনে ক্লিক করুন (কোনো git কমান্ড লাগবে না) — index.html, style.css, script.js আর assets ফোল্ডারের ছবিগুলো আপলোড করে **Commit changes** চাপুন।
3. রিপোজিটরির **Settings → Pages**-এ যান।
4. "Source"-এর নিচে **Deploy from a branch** সিলেক্ট করুন, ব্রাঞ্চ হিসেবে **main** আর ফোল্ডার হিসেবে **/ (root)** বাছাই করে **Save** চাপুন।
5. এক-দুই মিনিট অপেক্ষা করুন, তারপর `https://yourusername.github.io/portfolio/` ঠিকানায় গিয়ে দেখুন — লাইভ হয়ে গেছে!

**কোনটা বেছে নেবেন?** সবচেয়ে দ্রুত ও সহজ লাইভ লিংকের জন্য Netlify Drop ব্যবহার করুন। যদি ভবিষ্যতে GitHub আর Git শেখার ইচ্ছা থাকে, GitHub Pages ভালো অনুশীলন।

- **সবচেয়ে বেশি এডিট করবেন:** **index.html** (টেক্সট/লিংক/প্রজেক্ট) আর **style.css** (রং/ফন্ট/ডিজাইন)। **script.js** প্রায় কখনোই বদলানোর দরকার হবে না।
- **কীভাবে রান করবেন:** portfolio ফোল্ডারে **index.html**-এ ডাবল-ক্লিক করুন, অথবা VS Code-এ **Live Server** ব্যবহার করুন।
- **কীভাবে পাবলিশ করবেন:** পুরো portfolio ফোল্ডারটা **[app.netlify.com/drop](https://app.netlify.com/drop)**-এ drag & drop করুন — সাথে সাথে একটা লাইভ লিংক পাবেন।
